# rWikiText C ABI (v1)

`include/rwikitext.h` defines the version 1 C ABI for `librwikitext`.

- See @ref rwikitext.h for the full API reference, request/response JSON schemas, lookup callback contract, and C usage example.
- Core entry points:
  - `rwikitext_v1_abi_version()`
  - `rwikitext_v1_convert()`
  - `rwikitext_v1_free()`
  - `rwikitext_v1_reply_set()`
