# Triage labels

Use these GitHub label names for the corresponding roles in the engineering skills.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | The issue requires a human to implement it. |
| `wontfix` | `wontfix` | A maintainer has decided to leave the issue unaddressed. |
